# Journey

1. A guest opens `/`, sees common actions, and submits Home search.
2. `/capabilities?q=...` renders visible matching capabilities and retains filters.
3. Capability detail explains its resolved/default app, alternatives, and status.
4. Open uses only the approved catalog URL in a labeled new tab.
5. Application browsing supports query/category/availability URL state and details.
6. An application detail links to each capability without mutating a preference.
7. A guest attempting to save is directed to login with a local return path.
8. A member saves or resets a preference; failure retains the chosen UI state.
9. Empty results and missing/unconfigured providers present useful recovery links.
